# Centurion Theme Showcase Scripts

This directory contains showcase scripts in various programming languages to demonstrate the Centurion theme's syntax highlighting capabilities.

## 📂 Files

### `showcase.py`
**Python** - Comprehensive demonstration of Python syntax highlighting
- Modern Python 3.9+ syntax
- Dataclasses, Enums, Type hints
- Abstract base classes and inheritance
- Docstrings and comments
- Collections and comprehensions

**Best for**: Creating screenshots showing Python code

### `showcase.js`
**JavaScript** - Pure JavaScript with ES6+ patterns
- Classes and object-oriented design
- Arrow functions and modern syntax
- JSDoc comments and documentation
- Map and Set collections
- Higher-order functions and filters

**Best for**: Web development and Node.js workflows

### `showcase.rb`
**Ruby** - Idiomatic Ruby patterns
- Classes and modules
- Blocks, procs, and lambdas
- String interpolation and formatting
- YARD documentation syntax
- Filter and sort operations

**Best for**: Ruby on Rails and backend development

### `showcase.go`
**Go** - Concurrent and efficient systems programming
- Packages and imports with best practices
- Structs and methods
- Interfaces and type definitions
- Goroutines and channels (demonstrated patterns)
- Error handling with sentinel values
- Standard library usage

**Best for**: Systems programming, microservices, and backend APIs

### `showcase.ts`
**TypeScript** - Object-oriented TypeScript patterns
- Interfaces and type definitions
- Class-based task manager
- Generics and union types
- Callbacks and decorators
- Comments and JSDoc

**Best for**: Showcasing TypeScript syntax and types

### `showcase.tsx`
**React TypeScript** - Modern React with TypeScript
- Functional components with hooks
- useState, useCallback, useMemo
- TypeScript interfaces
- Styled components
- Modern JavaScript patterns

**Best for**: Web development and React workflows

### `showcase.rs`
**Rust** - Idiomatic Rust code
- Enums with derive macros
- Structs and trait implementations
- Pattern matching
- Error handling with Result
- Unit tests
- Module organization

**Best for**: Systems programming and Rust enthusiasts

### `showcase.html`
**HTML/CSS** - Complete showcase webpage
- Semantic HTML5 structure
- Modern CSS Grid and Flexbox
- CSS Variables and custom properties
- Responsive design
- Interactive button states

**Best for**: Web design and CSS showcase

## 🎨 How to Use for Screenshots

1. **Open in VS Code**
   - Open the Centurion theme project in VS Code
   - Install the theme (press F5 or use `code --install-extension`)

2. **Choose a Language**
   - Open the corresponding showcase file:
     - Python: `showcase.py`
     - TypeScript: `showcase.ts`
     - React: `showcase.tsx`
     - Rust: `showcase.rs`
     - Web: `showcase.html` (open in browser)

3. **Adjust Editor Settings** (Optional)
   - Font: Fira Code, JetBrains Mono, or Menlo
   - Font size: 14-16px (good for visibility)
   - Line height: 1.5-1.6
   - Word wrap: Enabled for better framing

4. **Take Screenshot**
   - Use VS Code's built-in screenshot (⌘+Shift+P → Screenshot)
   - Or use your OS screenshot tool
   - Or use a tool like:
     - [ScreenFloat](https://screenfloat.com/) (macOS)
     - [Greenshot](https://getgreenshot.org/) (Windows)
     - [Flameshot](https://flameshot.org/) (Linux)

5. **Post-Processing** (Optional)
   - Add title/description overlays
   - Add rounded corners and drop shadow
   - Crop to relevant code section
   - Add a subtle border or frame

## 💡 Tips for Great Screenshots

- **Use Split View**: Open two files side-by-side to showcase variety
- **Highlight Key Lines**: Use bookmarks or search highlighting
- **Show Different Sections**: Scroll through different parts of the file
- **Full Screen**: Maximize editor for clean, distraction-free shots
- **Keep Code Visible**: Avoid too much whitespace or toolbars
- **Theme Context**: Include VS Code theme selector showing Centurion selected
